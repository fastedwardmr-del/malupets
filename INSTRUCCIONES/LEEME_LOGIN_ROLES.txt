MALUPETS - LOGIN + USUARIOS + ROLES/PERMISOS
=================================================

QUE AGREGA ESTE PAQUETE
-----------------------
1. Login real contra Cloudflare D1.
2. Contraseñas almacenadas con PBKDF2-SHA256 + salt.
3. Sesiones de 12 horas.
4. Bearer token automático en las llamadas API.
5. Protección de endpoints del Worker.
6. Roles:
   - ADMIN
   - VENTAS
   - SPA
   - CONSULTA
7. Permisos configurables por módulo.
8. Ocultamiento automático de opciones del menú según permisos.
9. Protección para impedir abrir directamente páginas sin permiso.
10. Administración de usuarios desde Configuración.
11. Cierre de sesión.
12. Usuario administrador inicial.

INSTALACION FACIL
-----------------
1. Copia el contenido del ZIP sobre:
   C:\Proyectos\Malupets

2. Acepta reemplazar archivos.

3. En la raiz C:\Proyectos\Malupets haz doble clic en:
   install-auth-roles.bat

Ese archivo:
- crea las tablas users y sessions;
- crea el administrador inicial;
- despliega la API;
- despliega Pages.

INSTALACION MANUAL
------------------
Desde:
C:\Proyectos\Malupets\apps\api

Ejecuta:

npx wrangler d1 execute malupets-db --remote --file=../../database/migrations/03_auth_roles.sql

Luego:

npx wrangler deploy

Luego:

cd ..\web

Y:

npx wrangler pages deploy . --project-name=malupets

SEGURIDAD
---------
- No se guarda la contraseña en texto plano.
- El Worker valida permisos, no solo el frontend.
- Ocultar un botón NO es la seguridad principal: la API también bloquea
  operaciones no autorizadas.
- La sesión expira automáticamente.
- Las imágenes de productos siguen siendo públicas únicamente para poder
  mostrarlas mediante etiquetas <img>; la creación/edición/subida de imágenes
  sí está protegida.
